## 🔓 Open-Source GitHub Projects

Curated open-source video conferencing applications, virtual classrooms, and meeting platforms — **sorted in descending order by GitHub Stars** ⭐.

1. **[Jitsi Meet](https://github.com/jitsi/jitsi-meet)** [![GitHub stars](https://img.shields.io/github/stars/jitsi/jitsi-meet?style=social&color=white)](https://github.com/jitsi/jitsi-meet/stargazers)  
   🏆 Leading open-source WebRTC video conferencing platform. Features browser-based encrypted meetings, screen sharing, chat, recording (via Jibri), breakout rooms, and high horizontal scalability via Jitsi Videobridge.

2. **[LiveKit](https://github.com/livekit/livekit)** [![GitHub stars](https://img.shields.io/github/stars/livekit/livekit?style=social&color=white)](https://github.com/livekit/livekit/stargazers)  
   ⚡ Modern, distributed open-source WebRTC SFU and real-time media stack written in Go. Powers next-generation video/audio calling, AI agents, spatial audio, and custom conferencing applications with multi-platform SDKs.

3. **[Pion WebRTC](https://github.com/pion/webrtc)** [![GitHub stars](https://img.shields.io/github/stars/pion/webrtc?style=social&color=white)](https://github.com/pion/webrtc/stargazers)  
   🧩 Pure Go implementation of the WebRTC API. Highly modular, performant, and flexible library used globally to build custom SFUs, media bridges, and streaming engines.

4. **[coturn](https://github.com/coturn/coturn)** [![GitHub stars](https://img.shields.io/github/stars/coturn/coturn?style=social&color=white)](https://github.com/coturn/coturn/stargazers)  
   🌍 Free and open-source implementation of TURN and STUN Server for VoIP and WebRTC. Essential infrastructure backbone for NAT traversal and peer-to-peer connection relaying.

5. **[Screego](https://github.com/screego/server)** [![GitHub stars](https://img.shields.io/github/stars/screego/server?style=social&color=white)](https://github.com/screego/server/stargazers)  
   🖥️ Screen sharing for developers and teams. Lightweight, self-hosted WebRTC application with secure room sharing, low latency, and integrated TURN server.

6. **[BigBlueButton](https://github.com/bigbluebutton/bigbluebutton)** [![GitHub stars](https://img.shields.io/github/stars/bigbluebutton/bigbluebutton?style=social&color=white)](https://github.com/bigbluebutton/bigbluebutton/stargazers)  
   🎓 Open-source virtual classroom and web conferencing system built for online education. Offers interactive multi-user whiteboards, polling, breakout rooms, shared notes, session recording, and deep LMS integrations (Moodle, Canvas).

7. **[Janus Gateway](https://github.com/meetecho/janus-gateway)** [![GitHub stars](https://img.shields.io/github/stars/meetecho/janus-gateway?style=social&color=white)](https://github.com/meetecho/janus-gateway/stargazers)  
   🔌 General-purpose WebRTC server (C-based) designed as a modular media gateway. Supports SFU video rooms, SIP bridging, streaming, text room data channels, and custom plugins.

8. **[mediasoup](https://github.com/versatica/mediasoup)** [![GitHub stars](https://img.shields.io/github/stars/versatica/mediasoup?style=social&color=white)](https://github.com/versatica/mediasoup/stargazers)  
   🚀 Cutting-edge WebRTC SFU library (Node.js/Rust/C++) designed for building scalable multi-party video conferencing, low-latency broadcasting, and custom media pipelines.

9. **[Nextcloud Talk (Spreed)](https://github.com/nextcloud/spreed)** [![GitHub stars](https://img.shields.io/github/stars/nextcloud/spreed?style=social&color=white)](https://github.com/nextcloud/spreed/stargazers)  
   🔒 On-premises audio/video calling and chat integrated into Nextcloud. Provides end-to-end encryption, screen sharing, whiteboard, file collaboration, and federated communication.

10. **[OpenVidu](https://github.com/OpenVidu/openvidu)** [![GitHub stars](https://img.shields.io/github/stars/OpenVidu/openvidu?style=social&color=white)](https://github.com/OpenVidu/openvidu/stargazers)  
    📦 Complete developer platform to easily embed real-time video conferencing into web and mobile apps with full Docker stacks, recordings, and media moderation.

11. **[MiroTalk](https://github.com/miroslavpejic85/mirotalk)** [![GitHub stars](https://img.shields.io/github/stars/miroslavpejic85/mirotalk?style=social&color=white)](https://github.com/miroslavpejic85/mirotalk/stargazers)  
    ✨ Self-hosted WebRTC real-time video conference solution (P2P, SFU, and Broadcast variants) with whiteboard, file sharing, recording, chat, and simple single-container Docker setup.

12. **[Galène](https://github.com/jech/galene)** [![GitHub stars](https://img.shields.io/github/stars/jech/galene?style=social&color=white)](https://github.com/jech/galene/stargazers)  
    🪶 Ultra-lightweight WebRTC videoconferencing server written in Go. Engineered for low CPU/memory overhead, academic lectures, and high-density conferences.

13. **[PlugNMeet](https://github.com/mynaparrot/plugNmeet-server)** [![GitHub stars](https://img.shields.io/github/stars/mynaparrot/plugNmeet-server?style=social&color=white)](https://github.com/mynaparrot/plugNmeet-server/stargazers)  
    🧩 Fully customizable and embeddable open-source web conferencing system built on LiveKit. Features interactive whiteboard, polls, breakout rooms, speech-to-text, and client SDKs.

14. **[eduMEET](https://github.com/edumeet/edumeet)** [![GitHub stars](https://img.shields.io/github/stars/edumeet/edumeet?style=social&color=white)](https://github.com/edumeet/edumeet/stargazers)  
    🏫 Open-source WebRTC video conferencing system designed for research and higher education, based on Node.js and mediasoup.

15. **[Apache OpenMeetings](https://github.com/apache/openmeetings)** [![GitHub stars](https://img.shields.io/github/stars/apache/openmeetings?style=social&color=white)](https://github.com/apache/openmeetings/stargazers)  
    ☕ Enterprise open-source groupware and video conferencing tool providing video calls, document editing, whiteboard, and user moderation.

16. **[La Suite Meet](https://github.com/suitenumerique/meet)** [![GitHub stars](https://img.shields.io/github/stars/suitenumerique/meet?style=social&color=white)](https://github.com/suitenumerique/meet/stargazers)  
    🇫🇷 Sovereign open-source video meeting platform powered by LiveKit, Django, and React. Built for government and public sector privacy compliance.

17. **[Strive](https://github.com/Anapher/Strive)** [![GitHub stars](https://img.shields.io/github/stars/Anapher/Strive?style=social&color=white)](https://github.com/Anapher/Strive/stargazers)  
    🎤 Modern open-source video conferencing application with breakout rooms, talking queue moderation, screen sharing, and clean Vue/ASP.NET architecture.
