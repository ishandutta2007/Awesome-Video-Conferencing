# Awesome-Video-Conferencing

### Top Video Conferencing Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Real-Time Video Meetings, Screen Sharing, Collaboration, Webinars & Secure Communication*
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Video Conferencing**. These tools enable high-quality audio/video meetings, screen sharing, chat, recording, breakout rooms, virtual backgrounds, and integrations for teams, education, events, and remote collaboration.

**Examples** include Zoom, Google Meet, Microsoft Teams, Webex, Whereby, Jitsi Meet, Around, Livestorm, RingCentral Video, and BlueJeans (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, privacy-focused deployments, custom WebRTC stacks, and open media infrastructure — ideal for organizations, universities, developers, and privacy-conscious teams that want full control over their communications.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[Jitsi Meet](https://github.com/jitsi/jitsi-meet)**  
  Leading open-source video conferencing platform with browser-based meetings, screen sharing, chat, recording (via Jibri), breakout rooms, and end-to-end encryption options. Easy to self-host and highly scalable with Jitsi Videobridge.

- **[BigBlueButton](https://github.com/bigbluebutton/bigbluebutton)**  
  Open-source virtual classroom and web conferencing system optimized for education, with multi-user whiteboard, polling, breakout rooms, shared notes, recording, and deep LMS integrations.

- **[MiroTalk](https://github.com/miroslavpejic85/mirotalk)**  
  Self-hosted open-source WebRTC video conferencing (P2P and SFU variants) with high resolution support, screen sharing, chat, whiteboard, recording, and easy Docker deployment.

- **[LiveKit](https://github.com/livekit/livekit)**  
  Modern open-source WebRTC SFU and end-to-end realtime stack for building scalable video/audio applications, AI agents, and custom meeting experiences. Powers many production systems.

- **[Nextcloud Talk](https://github.com/nextcloud/spreed)**  
  Integrated open-source video & audio calls + chat for Nextcloud, with screen sharing, file sharing, federated chats, and seamless collaboration inside the Nextcloud ecosystem.

- **[Galène](https://github.com/jech/galene)**  
  Lightweight, efficient open-source videoconferencing server (Go + WebRTC) designed for low resource usage, lectures, small groups, and meetings.

- **[PlugNMeet](https://github.com/mynaparrot/plugNmeet-server)**  
  Scalable, customizable open-source web conferencing system built on LiveKit with whiteboard, polls, breakout rooms, recording, AI features, and easy embedding.

- **[La Suite Meet](https://github.com/suitenumerique/meet)**  
  Open-source video conferencing app powered by LiveKit (Django + React), optimized for large meetings, screen sharing, recording, transcription, and secure self-hosting.

- **[Strive](https://github.com/Anapher/Strive)**  
  Open-source video conference platform with breakout rooms, screen sharing, flexible permissions, moderated talking, and modern responsive UI.

- **[OpenVidu](https://github.com/OpenVidu/openvidu)**  
  Open-source platform for building and deploying WebRTC video applications with Kurento media server, recording, and full Docker Compose stacks.

- **[Janus Gateway](https://github.com/meetecho/janus-gateway)**  
  General-purpose open-source WebRTC server (SFU + plugins) widely used as the media backbone for custom video conferencing and streaming solutions.

- **[mediasoup](https://github.com/versatica/mediasoup)**  
  Powerful open-source WebRTC SFU library (C++/Node.js/Rust) for building high-performance, custom video conferencing and real-time media applications.

### Additional Strong Open-Source Options

- **LiveKit-based apps**: LiveKit Meet examples, OSSMeet, and various community frontends.
- **Education & collaboration**: Apache OpenMeetings, eduMEET, and classroom-focused forks.
- **Lightweight / specialized**: Screego (screen sharing), Ahey (embeddable P2P), Lantern (LAN/privacy-focused), and Jangouts (Janus-based).
- **Infrastructure**: coturn (TURN/STUN), Pion WebRTC, and SFU libraries for custom stacks.
- Many community **virtual background**, **transcription**, **recording**, and **SIP/WebRTC bridge** projects.
- Matrix/Element for federated chat + video, and WorkAdventure-style virtual office tools.

**Frameworks for building custom systems**: Combine **Jitsi** or **BigBlueButton** for ready-to-use rooms, **LiveKit** / **mediasoup** / **Janus** as the media server, **Next.js/React** or **Vue** frontends, **coturn** for NAT traversal, and optional AI (LiveKit Agents, transcription services) for intelligent meetings.

- Self-hosted open-source solutions require adequate server resources, TURN servers, bandwidth planning, security hardening, and ongoing maintenance for production reliability.
